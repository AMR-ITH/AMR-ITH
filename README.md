### 🎵 Hybrid Spotify Recommendation System

A **production-grade hybrid recommender** combining content-based and collaborative filtering. Designed for scalability, performance, and automated CI/CD deployment on AWS.

- 🧠 **Content-based** filtering using cosine similarity on song metadata
- 🤞 **Collaborative filtering** on a sparse matrix of 9.7M users × 34K songs (330M+ interactions)
- 🎯 Hybrid score: Weighted average of both methods for personalization
- ⚙️ ML Workflow: Versioned pipelines with DVC & Git, artifacts stored on AWS S3
- 🚀 CI/CD: Docker → GitHub Actions → AWS ECR → CodeDeploy (Blue/Green deployment)
- 🎵 Example: Recommends similar tracks to “Love Story” by Taylor Swift

**Tech:** `Python` · `Scikit-learn` · `DVC` · `Docker` · `GitHub Actions` · `AWS` · `Streamlit`
